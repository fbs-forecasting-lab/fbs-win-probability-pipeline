# Project Impact and Stakeholders

**Project:** Serverless FBS College Football Win-Probability Pipeline
**Group:** Hampton Abbott, Dharm Patel, Josh Livengood, Sarah Asianut Okwalinga

> This page reproduces the team's Project Impact and Stakeholders assignment and
> describes the project's intended goals. The current repository is a
> retrospective demonstration; real-time updating and serverless deployment are
> planned rather than implemented. See the [README](../README.md) for current status.

## Impact

This tool will provide real-time, automatically updating win-probability
estimates for FBS college football games. Unlike many existing tools that rely
on manual updates or are limited to major broadcast networks' proprietary
models, this pipeline runs serverlessly, making it lightweight, low-cost, and
easy to scale or extend to additional games and metrics without maintaining
dedicated servers.

## Stakeholders

The stakeholders for our project are college football fans, sports bettors,
fantasy football players, sports journalists and analysts, coaching staff, and
data engineers/data providers.

## Stakeholder needs

- **College football fans** need clear and consistently updated win predictions
  for each game.
- **Sports bettors** need timely and accurate predictions based on pregame
  information.
- **Fantasy football players** need information about player availability,
  matchups, and weekly games to help choose their lineups.
- **Sports journalists and analysts** need historical data, accurate
  predictions, and information on factors that may affect outcomes.
- **Coaching staff** need information about opponents, player availability,
  weather, team performance, and top players at each position.
- **Data providers and engineers** need reliable data and an automated system
  that can update information, fill in missing data, and manage changes in the
  data over time.

## Stakeholder benefits

College football fans benefit from easy-to-understand win predictions. Sports
bettors could use real-time data to make more informed decisions. Fantasy
football players could use predictions to help create better starting lineups.
Sports journalists and analysts would have updated weekly data to support their
analysis, while coaching staff could use the data to help prepare for upcoming
games.

## Stakeholder risks

Football fans and sports bettors may rely too heavily on predictions, which
could lead to poor or costly decisions if the model misses factors like weather
or injuries. Journalists could report incorrect information if the system has
errors, while coaches and analysts could make flawed conclusions if the model
does not account for team-specific changes.
